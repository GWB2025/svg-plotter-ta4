Fonts, styles and spacing

Choose Sans, Serif, Serif Italic or Script, or import a .ttf font. For another weight or style, import its own file, such as Bold or Italic. Each appears as a separate choice.

Automatic spacing leaves room for accents and descenders. Untick it to set larger gaps yourself. Every character occupies one column, including when using a proportional font; lines never wrap.

Font size and spacing are measured before fitting. Prepare to plot uses the page size and margin in Plot drawing and starts with Fit drawing to page, which scales the lettering too. Review the fitted size, rotation and physical pen there. Choose Keep original size and position to retain the size shown above. Preparing does not move the plotter. Save text saves the characters only; Export SVG preserves the chosen letter paths and size.
