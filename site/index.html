SVG PLOTTER 1.7.0 · PRE-RELEASE

SVG Plotter

Preview SVG artwork or text, choose your pens and plot colour by colour. Use the supplied Writing Robot T-A4 profile, configure a compatible GRBL Z-lift machine, or export prepared SVG for another plotter's own software.

Open the local app

Install and open the app on your Mac first

If you have the supplied Installer ZIP, extract it, finish any drawing and quit the old SVG Plotter, then open the included .pkg. Choose Continue, then Install. Open SVG Plotter from Applications afterwards. Your saved settings are retained and Python is included.

The supplied Apple silicon build requires macOS 15 or later. The installer is unsigned and the app is not Apple-notarised. See the installation guide for compatibility, opening instructions and validation status.

As of 29 October 2026, no downloads have been published in GitHub Releases. The current installer was supplied separately. GitHub's Code → Download ZIP contains source code; developers can follow the build guide or run .venv/bin/python launch.py after installing the source dependencies.

This page cannot launch the native app, start its server or connect to USB. Open the installed app first, then use the button above if you want its browser view. Opening the app does not start the robot: connect, clear the bed, home and confirm readiness in the app.
