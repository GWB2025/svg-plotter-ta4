Start the app on your Mac first

This page cannot start the Python server or connect to USB. Download the versioned Mac pre-release from GitHub Releases. Extract the ZIP, quit the old sender and drag SVG Plotter into Applications. See the installation instructions for compatibility and validation status. Developers can run .venv/bin/python launch.py from the repository folder, then use the button above.

First-time installation and README · User guide

Opening the app does not start the robot. Connect, clear the bed, home and confirm readiness in the local app.
