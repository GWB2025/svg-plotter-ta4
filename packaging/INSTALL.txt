SVG Plotter 1.6.0 — pre-release

New: Text & ASCII art. Open a .txt file with the normal file picker, or
use the new tab to paste/edit text. Fixed-width pen strokes preserve spaces,
columns and blank lines. Choose Prepare to plot, review the fitted preview and
physical pen, then use the normal drawing controls. Save text keeps your edits.

Ink stock. Add bottles, record RGB/HEX and paper/performance notes,
then link each refillable pen to its current ink in Pen stock. Use Copy ink RGB
to pen when needed. Export catalogue now includes inks, pens and themes.
Existing catalogues are upgraded on save; older apps cannot read the new format.
Keep an old-format export if you plan to downgrade.

Materials guide. Browse and search the supplied pens, inks and papers
comparison, with thanks to Dan Catt and links to his Pens & Paper lesson.

Pen stock > Pen colour swatches. Choose your Sharpie set or a single pen,
then Prepare swatch sheet. Default patches are 20 x 20 mm. The plotter pauses
for each labelled physical pen. Read the dry patches using the ColorReader phone
app, then use Enter RGB to save each reading to its pen.

If a drawing is running in an older version, let it finish before quitting
and replacing the app. Do not interrupt an active plot to install this update.

SVG Plotter — Mac installation

1. Open the DMG, or double-click the ZIP to unpack it.
2. Drag SVG Plotter into Applications, then open it from Applications.
   If you used a DMG, eject the disk image after copying.
3. Connect your T-A4 by USB. Select it and choose Connect.
4. Clear the bed, choose Home, load a small test drawing and confirm readiness.

Opening the application never connects or moves the plotter automatically.
Finish or cancel a drawing before closing the app. Paused jobs remain active.

Choose arm64 for Apple silicon (M-series), or x86_64 for an Intel Mac.
The local Apple silicon test build requires macOS 15 or later.
Test builds are not Apple-notarised. Only install a build from a source you trust.
If macOS blocks a trusted test build, use System Settings > Privacy & Security
and Open Anyway. Do not disable Gatekeeper.

Saved recovery records and logs:
~/Library/Application Support/SVG Plotter/

Before switching from the Terminal version, finish any drawing, disconnect
and stop that server. Do not run two senders against the same USB plotter.
Old logs are not migrated automatically. Complete or discard any old recovery
in the old app before switching.

The Postcard-trial folder contains exact-size scrap-paper checks. Read its
READ-ME.md before plotting. Physical recovery and registration validation
remain pending for this release.
