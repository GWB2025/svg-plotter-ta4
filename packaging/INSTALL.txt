SVG Plotter 1.8.1 — pre-release

INSTALL OR UPDATE

1. Save unsaved work. Finish or cancel an active drawing, then quit SVG Plotter.
   A paused drawing is still active. Stop any Terminal-based sender as well.
2. For an Installer ZIP: extract it, double-click the .pkg, then choose
   Continue and Install. Enter your administrator password if requested.
   For an application ZIP or DMG: copy SVG Plotter.app into Applications.
   Eject a DMG after copying. GitHub's source ZIP is not an application bundle.
3. Open Finder > Applications > SVG Plotter. Confirm version 1.8.1 in About.
4. Choose Your plotter before connecting. Keep the supplied Writing Robot T-A4
   profile for the original machine, refresh connections and select its USB port.
5. Clear the bed and homing path, choose Home, then secure scrap paper and fit
   the pen. Load a small test drawing, inspect the preview and confirm readiness.

Opening the app never connects or moves the plotter automatically. The installer
does not close a running app. No Mac restart or separate Python download is needed.

REQUIREMENTS

The supplied Apple silicon (arm64/M-series) build requires macOS 15 or later.
Intel (x86_64) builds require separate building and verification; this arm64
installer is not for Intel Macs. The app is ad-hoc signed and the installer is
unsigned; neither is Apple-notarised. If macOS blocks a trusted download, try
opening it, then use System Settings > Privacy & Security > Open Anyway.
Apple guidance: https://support.apple.com/en-gb/102445

VERSION 1.8.1

Clear text buttons are available below the ASCII editor, postcard message and
postal address. Each clears only its own text and keeps font/layout settings.
Use Undo in Postcard text or Undo clear in ASCII to restore cleared text.
ASCII Undo clear remains available until you type or open another file.
Clearing does not alter an already prepared drawing or erase saved files.
Save draft if you want to keep the cleared postcard for the next session.

VERSION 1.8.0

Text & ASCII art now shares your imported fonts with Postcard text. Choose
Font / style, then Font size (points) for 6–72 pt lettering. Automatic spacing
keeps the columns aligned; manual spacing is checked for clipping. Import a
font's own Bold or Italic .ttf file for those styles. Fit to spacing retains the
original ASCII sizing. Export SVG preserves the selected lettering and size.

VERSION 1.7.1

All four bundled postcard fonts now include Latin macrons, for example:
  Rōmānī īte domum
Bars are separate pen strokes, and ī has a dotless stem.

VERSION 1.7.0

Your plotter: add, duplicate, edit and select saved make/model profiles. Compatible
GRBL Z-lift machines can use configurable bed dimensions, axis directions, pen
heights, speeds and USB settings. New machines require a pen-clear calibration.
Other controller types use SVG export: choose Save prepared SVG and open it in
the machine's own software. The app does not directly control those protocols.
Profile changes require disconnection and no retained recovery.

Also included: SVG rotation and layered hatching, Text & ASCII art, postcard
message/address layout, stroke fonts and private TrueType import, positioning
guides, editable pen/ink stock, colour themes, labelled swatches, Materials guide,
pen-change prompts, parked pauses and interrupted-plot recovery.

YOUR SAVED DATA

Native app settings and recovery remain outside the application bundle:
  ~/Library/Application Support/SVG Plotter/
Updating the app preserves stock, themes, profiles, imported fonts, saved
postcard drafts and recovery records. Save edits before quitting. Catalogue
export backs up pens, inks and themes; back up the entire folder while the app
is closed to retain the other settings. Keep plotter-state.json and
plotter-job.json together for an interrupted drawing.

Source launches use logs/ in the repository. Data is not migrated between source
and native installations automatically. Complete or discard old recovery in its
original sender before switching. Never run two senders against the same plotter.
Catalogue format 2 (used since 1.5.0) imports format 1 backups; older apps cannot
read format 2. The installer uses bundle version checks to prevent downgrades.
